## 📋 Instruções de Uso

### Abrir Localmente
1. Clone o repositório
2. Abra `index.html` no seu navegador
3. Ou use um servidor local:
   ```bash
   python -m http.server 8000
   # ou
   npx http-server
   ```

### Deploy GitHub Pages
1. Vá para **Settings** → **Pages**
2. Escolha a branch `main` ou `master`
3. Deixe a pasta como `/` (root)
4. Clique em Save
5. Seu site estará disponível em: `https://<seu-usuario>.github.io/Okki-websolutions/`
